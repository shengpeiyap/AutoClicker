# Changelog

## 1.0.2 — 2026-10-27

- Applied the bundled mouse icon to the main and recording windows at runtime, in addition to the executable file icon.

## 1.0.1 — 2026-10-27

- Added an always-on-top option for the main window.
- Minimized the main window before keyboard automation so simulated keys go to the previously active application.
- Increased the recording panel size and split its controls across two rows.
- Added virtual-key and scan-code selection for recorded playback.
- Documented the unsigned Windows build warning.

## 1.0.0 — 2026-10-26

- Initial public release.
- Timed mouse clicks and repeated keyboard input with configurable intervals and run counts.
- Screen coordinate picker with DPI-aware coordinates.
- Keyboard input supports virtual-key and scan-code modes.
- Records mouse movement, clicks, drags, key presses, releases, and hold durations.
- Looped playback, JSON import/export, compact main window, and separate recording panel.
