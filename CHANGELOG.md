# Changelog

## 1.0.0 — 2026-10-26

- Initial public release.
- Timed mouse clicks and repeated keyboard input with configurable intervals and run counts.
- Screen coordinate picker with DPI-aware coordinates.
- Keyboard input supports virtual-key and scan-code modes.
- Records mouse movement, clicks, drags, key presses, releases, and hold durations.
- Looped playback, JSON import/export, compact main window, and separate recording panel.
